# LOGIC LAB

## 安装与本地启动

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的地址。类型检查和构建：

```sh
npm run typecheck
npm run build
```

时序引擎与快照的单元测试：

```sh
npm test
```

## 时序示波器

工作台顶部可在“组合逻辑工作台”和“时序示波器”之间切换。示波器为事件
驱动仿真，用于解释两条路径汇合时为什么会闪出窄脉冲：

- 给每个门分别设置上升、下降延迟（输入/输出元件为 0 延迟理想导线）；
- 在激励向量区按 `时间 标签=0 标签=1` 录入同一时刻的多路输入变化；
- 支持单步前进与连续运行，线路与波形只反映已经传播到当前时刻的值；
- 两种延迟模型：
  - **传输延迟**：窄脉冲按各边沿时间原样传播；
  - **惯性延迟**：短于门延迟的脉冲在事件到点时被滤除，且不会连带删掉
    其后的合法边沿；
- 切换模型会用同一激励、同一电路版本从头重新计算；
- 同一时刻到达的事件先合并再做拓扑收敛，结果与元件排列顺序无关；
- 运行中编辑电路时，旧波形保留并标明所绑定的电路版本（v1、v2…），
  新运行才使用新电路；
- 导出的波形 JSON 完整保留激励、时间单位、延迟模型与电路版本；
- 停止计算后，未算完的尾部以阴影标示为未计算，不会被画成稳定电平。
